Code and data for manuscript "Single-cell whole-genome sequencing reveals convergent evolution in Burkitt lymphoma"

Raw sequencing data can be obtained from EGA 
Post-PTATO data can be obtained from Mendeley (Steemers, Alexander (2026), “Single-cell whole-genome sequencing reveals convergent evolution in Burkitt lymphoma”, DOI: 10.17632/phk5jhhm7d.1)
