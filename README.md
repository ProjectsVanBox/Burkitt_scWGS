# Burkitt_scWGS
Code and data for manuscript "Single-cell whole-genome sequencing reveals convergent evolution in Burkitt lymphoma"

Data, including all post-PTATO filtered VCF files, can be obtained from Mendeley Database [https://data.mendeley.com/drafts/9pd6xdcpfh] with Reserved DOI: 10.17632/9pd6xdcpfh.1
